# DANE Data Lab 🇨🇴

Proyecto personal de análisis de microdatos del Departamento Administrativo Nacional de Estadística (DANE) de Colombia.

## Objetivo

Explorar y analizar datos reales para identificar problemas de calidad, descubrir patrones y responder preguntas relevantes mediante un proceso de análisis documentado y reproducible.

## Tecnologías

- **Python:** exploración, limpieza y transformación de datos.
- **SQL / PostgreSQL:** consultas y análisis de datos.
- **Power BI:** visualización de resultados, si resulta pertinente.
- **Git / GitHub:** control de versiones y documentación.

Las herramientas se utilizarán según las necesidades del análisis.

## Metodología

1. Explorar los conjuntos de datos y comprender su contexto.
2. Evaluar su calidad e identificar problemas.
3. Limpiar y transformar los datos cuando sea necesario.
4. Formular preguntas y realizar el análisis.
5. Comunicar los hallazgos mediante tablas, visualizaciones y documentación.

## Estado actual

**En preparación:** recopilación e inspección inicial de los microdatos.

## Fuente de datos

Departamento Administrativo Nacional de Estadística (DANE), Colombia.

Los conjuntos de datos seleccionados y sus respectivas fuentes se documentarán a medida que avance el proyecto.
